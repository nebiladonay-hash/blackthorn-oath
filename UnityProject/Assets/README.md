# Unity assets

Import source assets only after recording:
- original download URL and creator;
- exact license and commercial-use terms;
- file size and format;
- mesh scale and forward axis;
- rig/skeleton type and animation clip names;
- material/texture dependencies.

The first candidate imports are the existing CC0 cathedral, Silver Knight and T1 Sentinel listed in the original Godot project's `assets/models/README.md`. Their GLB files are downloaded by the existing script and are not committed as binaries. Confirm the current download links and license terms before importing them into Unity.

KayKit's free CC0 assets are the preferred art direction when a matching model/animation exists. Do not assume every pack or tier is free; record the exact package license before shipping.
